# PerfumeBlending · 香境

> 一炷烟中得意，九衢尘里偷闲。

一个中国风调香主题网站，撷取《香乘》等古籍香方之雅，融现代香水「前调 / 中调 / 后调」之趣，以纯原生前端技术呈现合香文化，并内置一款模拟和香的互动小游戏。

## ✨ 特性

- **水墨动效背景** — 墨晕云层漂移 + 飘落香料粒子，宣纸 / 朱砂 / 金 / 玉中国风配色
- **香方雅集** — 七方合香卡片，含香铭、香料配比条形图（滚动触发动画）
- **制香手法** — 选材配伍、炮制修治、捣碾成粉、和泥成型、窖藏陈化五步详解
- **非遗技艺** — 药香同源、窖藏陈化、打香篆、香席雅集四大板块
- **模拟和香小游戏** — 拖动香料按「君臣佐使」配伍，系统自动打分

## 🚀 快速开始

项目为纯原生 HTML / CSS / JS 单文件，零依赖、零构建。

1. 克隆仓库：

   ```bash
   git clone git@github.com:MiChuan/PerfumeBlending.git
   ```

2. 直接用浏览器打开 `index.html`，或启动任意静态服务器：

   ```bash
   # Python
   python -m http.server 8000

   # Node.js
   npx serve .
   ```

3. 访问 `http://localhost:8000` 即可。

## 🚢 GitHub Pages 部署

本项目为纯静态站点，零构建即可部署。

1. 打开仓库页面 → **Settings** → **Pages**；
2. 在 **Build and deployment** 中，**Source** 选择 **Deploy from a branch**；
3. **Branch** 选择 `main`，目录选 **`/ (root)`**，点击保存；
4. 等待几分钟，即可通过 `https://<用户名>.github.io/PerfumeBlending/` 访问。

> 由于站点入口为根目录的 `index.html`，无需额外构建步骤，GitHub Actions 会自动完成发布。

## 🎮 模拟和香玩法

1. 系统随机生成一炉「目标香方」，并标注君臣佐使配比；
2. 拖动滑杆，投入沉香、檀香、雪松、玫瑰、龙涎等香料；
3. 点击「焚香成韵」，系统按配比契合度打分，并提示多放 / 少放的香料；
4. 可「重开一炉」反复挑战。
